# Alltagsteam

The Alltagsteam website, built with Astro 7, React 19, Tailwind CSS 4, and Framer Motion.

## Development

Use Node.js 22.12 or newer (Node.js 24 LTS recommended) and npm 9.6.5 or newer.

```sh
npm ci
npm run dev
```

Open http://localhost:3000. The development command prepares responsive images
before starting Astro. If you add or replace an image while the server is running,
restart it to update the generated assets and manifest.

## Structure

- `src/pages/index.astro`: homepage and React island boundaries.
- `src/pages/impressum.astro` and `src/pages/datenschutz.astro`: static legal pages.
- `src/layouts/Layout.astro`: document, German metadata, favicon, self-hosted fonts.
- `src/components`: existing React presentation and interactive components.
- `src/styles/globals.css`: Tailwind entry point and shared styles.
- `src/config/motion.ts`: global animation switch.
- `src/pages/api/contact.ts`: server endpoint for contact submissions.
- `src/lib/contact.ts`: request validation and email delivery.
- `public`: original images and favicon.

Astro prerenders all three pages. The header and hero hydrate immediately;
the contact area hydrates when visible. All other sections, the legal pages,
the footer, and the feature strip are static HTML. React and Framer Motion
remain in use to preserve the existing interactions. Next.js is no longer used.

DM Sans and Cormorant Garamond are bundled locally through Fontsource.
Visitors do not fetch fonts from Google. The shared `Image` component uses
responsive WebP files generated by `scripts/prepare-images.mjs` at quality 95,
with intrinsic dimensions, lazy loading, and priority loading for the hero/logo.
Original images remain unchanged. Generated images and the manifest are ignored
by Git and recreated by `dev`, `check`, and `build`.

## Contact email

Copy `.env.example` to `.env` and configure:

- `RESEND_API_KEY`: Resend API key.
- `CONTACT_EMAIL`: recipient (defaults to `info@alltagsteam.com`).
- `CONTACT_FROM_EMAIL`: sender identity; use a verified sender for production.

The form posts JSON to `/api/contact`. The endpoint validates required fields
and a honeypot, then sends through Resend. Without an API key, development
logs the submission and returns success. Production returns HTTP 503 until
email delivery is configured. Credentials are read only on the server.

## Checks and production

```sh
npm run check
npm run lint
npm test
npm run build
npm run test:smoke
npm start
```

The tests mock email delivery; they do not send messages. `npm run check`
checks both Astro and TypeScript files.
`npm run test:smoke` checks the production build on a temporary local server at
port 4391, with email delivery explicitly disabled.

The standalone Node server serves the prerendered pages, assets, and contact
endpoint from `dist/client` and `dist/server`. Deploy both directories together
with the installed production dependencies. `npm start` loads `.env` if present;
environment variables supplied by the host take precedence. Set `HOST` and
`PORT` to configure its binding (this project defaults to localhost:3000).
`npm run preview` is also available for a local production preview.

The contact API requires Node hosting; serving only the static files omits email
delivery. No hosting service has been changed by this migration.
